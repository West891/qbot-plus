Политика конфиденциальности

Расширение: Q-bot PLUS, версия 1.0
Дата: 22 сентября 2026 г.

Эта политика описывает, какие данные обрабатывает расширение для браузера Chrome «Q-bot PLUS» и зачем. Расширение помогает автоматизировать действия на сайте брокера Quotex по команде пользователя.

Какие данные обрабатываются

  • Идентификатор аккаунта Quotex. Расширение читает ID пользователя со страницы брокера.
  • Баланс и результат сессии. Со страницы читается отображаемый баланс, чтобы показать прибыль или убыток и соблюдать лимиты, которые задал пользователь.
  • Настройки робота. Стратегия, сумма, шаги мартингейла, stop loss, take profit и признак VIP хранятся локально в браузере.
  • Торговый символ. При работе робота на сервер сигналов отправляется название валютной пары, например EUR/JPY.
  • Скриншот вкладки. Только если пользователь сам нажимает кнопку AI-анализа. Снимок видимой части страницы может содержать баланс, график и другие данные, которые в этот момент показаны на экране.

Расширение не запрашивает пароль, не читает сообщения, не отслеживает историю посещений других сайтов и не подменяет cookie партнёрских программ.

Куда передаются данные

Часть данных уходит на серверы, которые нужны для работы функций расширения:

  • https://ai-tradingbot.pro — проверка статуса доступа по ID аккаунта, получение торгового сигнала и загрузка скриншота для AI-анализа.
  • https://ai-tradebot.com — получение торгового сигнала для демо-счёта.

Ссылки на youlink.biz открываются только если пользователь нажимает их сам. Автоматического перехода и записи cookie нет.

Данные не продаются. Они используются, чтобы проверить доступ, получить сигнал, выполнить запрошенный анализ и сохранить настройки робота на этом устройстве.

Где данные хранятся

Настройки, ID аккаунта, стартовый баланс и служебные счётчики робота хранятся в localStorage страницы брокера в вашем браузере. Эти данные не отправляются отдельным архивом: на сервер уходят только ID, символ пары и скриншот, если вы запустили AI-анализ.

Срок хранения на серверах ai-tradingbot.pro и ai-tradebot.com определяется операторами этих сервисов и нужен для работы доступа, сигналов и анализа.

Зачем это нужно

  • отличить бесплатный доступ от VIP и показать соответствующий интерфейс;
  • запросить направление сделки для выбранной пары;
  • выполнить AI-анализ графика по явному действию пользователя;
  • запомнить настройки и не открывать новую сделку вне заданных лимитов.

Удаление данных

Локальные данные можно удалить, очистив данные сайта брокера в настройках Chrome или удалив расширение. После удаления расширения локальные настройки, сохранённые расширением, перестают использоваться. Чтобы удалить ID, скриншоты или результаты анализа на сервере, напишите оператору сервиса ai-tradingbot.pro.

Дети

Расширение не предназначено для лиц младше 18 лет и сознательно не собирает данные детей.

Изменения

Если состав данных или адреса серверов изменятся, эта страница будет обновлена. Дата в начале документа показывает последнюю редакцию.
